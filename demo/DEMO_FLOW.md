# Recorded demo flow (about 3 minutes)

1. **Overview:** “We built a scientist that must earn each forecast on an unseen origin.” Read the measured pooled skill and coverage from the page. State the agent mode and any fallback warnings exactly as displayed.
2. **Recorded replay:** Click “Play recorded demo.” Explain that each revealed point is the cumulative official score of predictions made before that origin’s outcomes were available. The zero line is drift, not last value. If the line loses, say so.
3. **Research log:** Show a rejected hypothesis and its actual reason. Explain which origins were used for tuning and which were reserved for the critic. Do not claim statistical significance when the recorded interval includes no improvement.
4. **Forecast explorer:** Search H100, select a series, and read its instrument and benchmark contract. Show q10/q50/q90 at 1, 3, and 7 days. Download the actual submission CSV.
5. **Economic view:** Clearly say “argued, not scored.” Show assumptions and dated citations. If external evidence is missing, say that the researcher could not run live.
6. **Reproduce:** Show acceptance check results and the single offline command. Explain what is cached, what lives in shared memory, and whether any API calls were actually made. Download findings.

The replay animates existing measured results. It does not run new experiments or simulate agent activity. November 7–13 truth is not in the participant pack; historical scores must never be described as the final submission score.
